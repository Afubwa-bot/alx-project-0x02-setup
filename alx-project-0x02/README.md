# alx-project-0x02-setup

This project was scaffolded using `npx create-next-app@latest` with TypeScript, ESLint, and Tailwind CSS enabled.

## Project Structure

- `pages/`: Contains the main application pages.
  - `index.tsx`: The home page.
- `components/`: Reusable React components.
  - `layout/`: Components related to the overall page layout.
    - `Header.tsx`: The application header.
- `interfaces/`: TypeScript interface definitions.
  - `index.ts`: Central file for interface exports.
- `public/`: Static assets (images, fonts, etc.).
  - `assets/images/`: Directory for images.
